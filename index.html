Python / PyPI

kappalogic

離散論理を、微分可能な実数の式に書き直す

PyPI 公開済み 基本ブロックは1つだけ

kappa(x/ξ) = tanh(x/ξ) という唯一の基本ブロックだけで、AND / OR / XOR や 比較演算、場合分けを「実数上の滑らかな式」として書き直すライブラリ。 ξ→0 で厳密な離散論理に、ξ>0 で微分可能な緩和になります。 同じ tanh が熱核・フェルミ分布・キンクソリトン・双曲幾何・情報幾何に共通して現れることを、 手を動かして検証しながら積み上げました。

C++ / C# / D3D12

PEAK-HLSL

ビルド済みゲームに、あとからシェーダーを差し込む

.exe を書き換えずに注入 D3D12 デバイスを横取り

PEAK のレンダリングパイプラインは URP Forward なので、本来ビルド後にカスタムシェーダーを 挿すことはできない。BepInEx で .dll を注入し、リフレクションで private フィールドを叩き、 UnsafePass で設定フラグを強制的に立てる。C++ 側では ID3D12Resource::GetDevice() 経由で Unity が作ったデバイスを横取りして同期させ、画面全体を1枚の大きな三角形で覆って最適化。

こまかい話

ここから下は履歴書ではありません。なぜそうなったか、の話です。

  1. 2004.07

    熊本で生まれる

    母がルーマニア人ということもあり、幼少期には何度か母国を訪れています。 強く残っているのは移動の大変さで、空港で2日ほど待機したこともあるほど、道のりは長く険しいものでした。 幼い頃から創造が好きで、自由帳や運動場でゲームを自作して遊ぶのが大好きでした。

  2. 2011.04

    はじめてのプラグイン制作 ／ チートとデコンパイル

    いつのまにか覚えたインタプリタ言語で、Minecraft の改造にのめり込みました。 LAN 公開から始め、UPnPCJ でのポート開放、API が豊富なサーバーラッパーを導入するなどして、 ネットフォーラムに掲載しました。

  3. 2021.08

    モンタナ大学 留学プログラム 修了

    高校一年生で英検準一級を取得後、全学年の英単語テストやユニセフ主催のボランティア活動に注力し、 県代表の派遣学生として ELI プログラムに選抜されました。 コロナ禍によりオンラインの受講となるも、多国籍な環境下、全編英語の議論に粘り強く対応し、共同プロジェクトを完遂。 帰宅中、母から「なにがほしい？」と訊かれた私は、新品のパソコンではなく、なぜか咄嗟に中古のオシロスコープを指しました。

  4. 2023.03

    高校時代 ／ 「最強になること」

    当時の私が最優先していたのは、ゲームで「最強になること」でした。 何が勝敗を左右するか理解するにつれ、それを徹底的に突き詰めるように。 BananaShooter ではキルレシオ47、ボルトカップでは優勝、Hypixel の PVP では連続79勝で記録を更新、 ULTRAKILL や CupHead では S ランクコンプリート。 結果、ほとんどの大会で出禁になり、チート疑惑はもはや日常だったので、画面共有はいつでも常備していました。

  5. 2023.04

    専門学校 ／ 博多での2年間

    長らくコミュニティ主をしている私の強みは、全体像を把握した上で適切に動くこと。 ホスティングからコーディング、デバッグ、レベルデザイン、モデリング、バランシングまでこなしてきた経験から、 どの工程がボトルネックになるかを直感的に察知できます。 企画書や仕様書、シナリオ作成の基本、ビジネスマナーなどを押さえ、より深く学べる環境を目指して中退。 この頃、炎上や暴露に頼らないゲーム実況で20万再生を超えました。

  6. 2024.06

    学生寮の寮食補助、そして熊本へ

    中退後の約一年間は、ゲームサーバーの運営を続けながら、当時居住していた寮の寮長に直接交渉し、 寮食のスタッフとして従事させていただきました。2025年3月に、契約期間満了をもって退職。 実家のある熊本に戻って就職活動の準備を本格化させ、その一歩として2025年7月に準中型免許を取得。 それから現在まで、熊本市の下通でバーテンダーのアルバイトをしております。

  7. 2026

    METAL GARDEN、そして現在

    放送大学の情報コースに入り直し、「METAL GARDEN」という屋号で個人事業をはじめました。 プログラミングと Minecraft を通したオンライン英語講師です。 事業用の口座を分け、事業計画書も通っていて、いまは親の扶養内でなんとかがんばっています。 これからはチーム規模での課題解決に挑みたい。
